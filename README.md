# LEQI — 韩国服装独立站

面向韩国市场的服装电商网站（韩语界面），纯静态 HTML/CSS/JS，无需构建，可直接部署到 GitHub Pages、Netlify、Cloudflare Pages 等。

## 已有功能

| 页面 | 文件 | 说明 |
|---|---|---|
| 首页 | `index.html` | 主视觉、分类入口、新品、热销、服务说明 |
| 商品列表 | `shop.html` | 分类筛选（NEW / BEST / 상의 / 하의 / 아우터 / 원피스 / ACC）、排序 |
| 商品详情 | `product.html?id=p001` | 选颜色/尺码/数量、尺码表、配送退换说明、相关推荐 |
| 购物车 | `cart.html` | 改数量、删除、满 50,000원 免运费提示 |
| 结账 | `checkout.html` | 订购人/收货人信息、韩国地址搜索（Kakao 우편번호）、手机号自动格式化、支付方式选择 |
| 下单完成 | `order-complete.html` | 订单号、商品、收货地址、无存折汇款信息 |
| 条款 | `policy.html` | 配送·退换货说明、이용약관、개인정보처리방침（模板） |

页脚已按韩国《电子商务法》要求预留了经营者信息栏位。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 怎么修改

- **商品**：编辑 `assets/js/data.js`。目前商品图是自动生成的示意插画，换成真实照片只需给商品加一行 `image: 'assets/img/xxx.jpg'`。
- **店铺信息、运费、银行账户**：编辑 `assets/js/store.js` 顶部的 `SHOP` 对象。
- **样式/颜色**：编辑 `assets/css/style.css` 顶部的 `:root` 变量。

## 上线前必须完成（韩国）

1. **사업자등록**（营业执照）：外国人可以注册个人或法人经营者。
2. **통신판매업 신고**（网络销售申报）：在区厅（구청）或政府24 线上办理。
3. 把营业执照号、申报号、地址、客服电话等填进 `store.js` 的 `SHOP`（页脚会自动显示）。
4. **接入支付（PG）**：目前结账是**演示模式**，不会真的扣款。韩国常用 [토스페이먼츠](https://www.tosspayments.com/)（一个合同覆盖信用卡、카카오페이、네이버페이、토스페이）。接入需要一个小后端来做支付确认（confirm），代码位置在 `checkout.html` 里标了 `▼ 실제 운영 시` 的地方。
5. **订单存储与管理后台**：目前订单只存在买家浏览器里。正式运营需要数据库 + 后台（下一步可以做）。
6. 让律师或专业人士审核 `policy.html` 里的条款和隐私政策。
7. 购买域名，比如 `.kr` 或 `.co.kr`。

> 如果不想自己维护后端，也可以考虑 Cafe24 / 아임웹 等韩国建站平台，它们自带 PG 和后台；这个仓库可以作为设计和商品展示的参考。

## 用 GitHub Pages 免费上线（演示用）

仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后几分钟就能通过 `https://<用户名>.github.io/leqi/` 访问。
